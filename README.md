# cat-pics

2,000 cat pictures resized for Microsoft Teams cards (JPEG, max 1024px, under 1 MB, metadata stripped), served with GitHub Pages.

- Image URL pattern: `https://bcox-adusa.github.io/cat-pics/<filename>.jpg`
- List of every image URL: https://bcox-adusa.github.io/cat-pics/urls.json

Adaptive Card example:

```json
{ "type": "Image", "url": "https://bcox-adusa.github.io/cat-pics/8beed629e24af4f4285932ce5a67385f6bad5f4d5ce34c0286ce9a94dc70b796.jpg", "size": "Large" }
```
